NeonRelay NeonRelay.gd

extends RefCounted

UDP/DTLS relay server that routes packets between hosts and clients.

The relay does not inspect game packet payloads; it only reads protocol headers to determine routing destinations. One relay can host multiple concurrent sessions.

Call start_and_run on a dedicated thread, or call start and then drive the relay manually by calling process in a loop.

Extend this class and override _on_packet to add custom packet handling, replying with send.

funcstart_and_run()

Starts the relay and blocks in the processing loop until stop is called.

Run on a dedicated thread.

funcstart() -> bool

Binds the relay socket without blocking.

Returns true on success. After this returns, call process in a loop to route packets.

funcstop()

Stops the relay and closes the socket.

funcis_running() -> bool

Returns true if the relay is bound and processing.

funcprocess()

Receives all pending packets and routes them to their destinations.

Also runs periodic cleanup of stale sessions and timed-out pending connections. Called automatically by start_and_run.
