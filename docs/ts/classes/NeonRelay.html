Class NeonRelay

UDP relay server for the Neon multiplayer protocol.

Subclasses can intercept packets by overriding NeonRelay.onPacket and reply with NeonRelay.send:

class MyRelay extends NeonRelay {
  protected override onPacket(packet: NeonPacket, source: Address): boolean {
    return false; // fall through to default handling
  }
}
